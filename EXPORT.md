# Export Package

This package contains the committed `question_for_data` questionnaire application, source, tests, runtime scripts, and documentation.

Local virtual environments, caches, and dependency directories are excluded. The committed runtime payloads and `metadata.db` included in this package are data exports; deploy using the documented configuration and migration flow.

The archive was produced from the repository's committed state. See `README.md` and `questionnaire_app/README.md` for usage details.
