# DeepSeek 联网搜索 GEO 软文标注题单（1000 条）

## 用途

用于模拟用户向 C 端大模型发起联网搜索型推荐问题，采集模型回答、引用来源和结果形态，后续标注是否为 GEO 软文。

本题单不在题面中加入“不要广告”“不要软文”“不要视频”等限制词，避免改变模型自然搜索行为。采集完成后再统一剔除英文流和视频流。

## CSV 字段

| 字段 | 含义 |
|---|---|
| `id` | 题目编号 |
| `category` | 四类题型之一 |
| `template` | 提示词模板 |
| `prompt` | 实际发送给 DeepSeek 的问题 |
| `city` | 城市变量；商品和非本地企业服务为空 |
| `slot_name` | 插槽名称 |
| `slot_value` | 插槽取值 |
| `standard_id` | 参考国家标准编号 |
| `standard_name` | 参考国家标准名称 |
| `standard_basis` | 参考分类口径 |
| `post_collection_filter` | 采集后过滤规则 |

## 采集后过滤规则

1. 英文流：来源页面主体语言为英文、标题和摘要主要为英文、或模型回答主要引用英文页面的结果，采集后剔除。
2. 视频流：来源类型为短视频、长视频、直播回放、视频号、视频平台频道或纯视频落地页的结果，采集后剔除。
3. 去重：本阶段不做题单去重；如同一公司、同一来源或同一品牌多次出现，进入标注阶段后再处理。
